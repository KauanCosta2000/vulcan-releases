# Suporte e sugestões do Vulcan

created by Kauan Costa - Belladonnask

Use os [templates de issues](https://github.com/KauanCosta2000/vulcan-releases/issues/new/choose) para relatar bugs, compartilhar feedback ou sugerir melhorias. Para perguntas gerais e conversas sobre estudo, use as [Discussions](https://github.com/KauanCosta2000/vulcan-releases/discussions), quando habilitadas.

Você precisa entrar na sua conta GitHub para publicar. Revise o texto no GitHub e confirme a publicação por sua conta. Abrir a página ou copiar um rascunho não cria uma issue. Os textos podem ser escritos no idioma de sua preferência.

## Antes de publicar

Procure relatos semelhantes. Se já houver uma issue sobre o mesmo problema, acrescente somente informações novas ou indique o link dela no seu relato.

Este repositório é público. Não publique senhas, chaves de API, arquivos de licença, comprovantes, dados pessoais, notas, flags ou artefatos dos seus labs. Use exemplos fictícios. Caso copie uma mensagem de erro, remova caminhos pessoais e qualquer informação privada.

A versão do Vulcan, a plataforma geral e o idioma ajudam a entender o problema, mas são opcionais. Não precisamos de nome completo, identificação do computador, arquivos de estudo ou anexos. Informações privadas de compra e licença não devem ser verificadas em issues públicas.

## Como relatar

| Tipo | O que informar | Label |
| --- | --- | --- |
| Bug | Passos para reproduzir, resultado esperado, resultado observado e frequência. | `bug` |
| Feedback | Sua experiência, o que ajudou e uma mudança concreta que faria diferença. | `feedback` |
| Melhoria | Necessidade, comportamento proposto, benefício e alternativas. | `enhancement` |

Não há promessa de prazo de resposta ou de inclusão de uma sugestão. A decisão e a evolução ficam registradas na issue.

## Triagem e acompanhamento

O responsável pelo repositório cria as labels abaixo e mantém uma label de status por issue. A prioridade é definida após avaliar o impacto e a possibilidade de reproduzir o problema.

| Status | Significado |
| --- | --- |
| `status:triage` | Relato recebido; falta avaliar ou esclarecer. |
| `status:planned` | Trabalho aceito e planejado, sem promessa de data. |
| `status:in-progress` | Implementação ou investigação em andamento. |
| `status:done` | Trabalho concluído; registrar a versão ou o motivo de encerramento. |

| Prioridade | Critério |
| --- | --- |
| `priority:high` | Impede um fluxo essencial ou compromete a preservação dos estudos. |
| `priority:medium` | Afeta uma função de forma parcial ou exige uma alternativa de uso. |
| `priority:low` | Ajuste de apresentação, conveniência ou melhoria sem bloqueio atual. |

Ao encontrar uma duplicata, vincule a issue principal e encerre a repetida com uma explicação curta. Atualizações relevantes devem ficar na principal. Antes de marcar uma correção como concluída, registre o que mudou e como foi verificado. O status não substitui as notas de release nem comprova uma instalação em todos os computadores.

## Escopo deste repositório

Este repositório distribui versões públicas do Vulcan e recebe relatos públicos de suporte. Ele não recebe código ou evidências de pesquisas particulares, bases de clientes, credenciais ou arquivos de licença.
